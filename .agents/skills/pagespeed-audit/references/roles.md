# Specialist roles

The coordinating agent acquires PSI evidence once. Send each role sanitized reports or relevant excerpts with timestamps, strategies, final URL and known stack. Prefer installed project agents named below. Where custom definitions are unavailable, delegate with the equivalent role instructions. Roles are read-only and use the evidence provided. Prevent repeated requests to Google by asking specialists to identify gaps for the coordinator.

| Agent | Job | Output to coordinator |
| --- | --- | --- |
| psi-field | Interpret CrUX by device and scope | p75 values, metric coverage, assessment and confidence limits |
| psi-lab | Interpret Lighthouse by page and device | Lab metrics and up to three evidenced causes, with resource or selector when known |
| psi-implementation | Map findings to the available stack | Reversible actions, settings or component owner, regression checks and rollback |
| psi-review | Check the draft report against the sources | Unsupported claims, missing caveats, overlapping savings and inaccurate verification claims |

Run field and lab in parallel. Send their reconciled findings to implementation and then send the draft and its evidence to review. Resolve conflicts with the source measurements. Keep one user-facing report.
